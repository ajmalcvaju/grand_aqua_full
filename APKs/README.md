# Grand Aqua Mobile APKs Directory
This directory holds compiled Android APKs for Grand Aqua:
- `Grand_Aqua_Buyer.apk`
- `Grand_Aqua_SuperAdmin.apk`
- `Grand_Aqua_Salesman.apk`

Note: Binary `.apk` files are excluded from Git to prevent repository bloat and respect GitHub's 100MB file limit.
Build debug APKs locally using:
```bash
flutter build apk --debug
```
